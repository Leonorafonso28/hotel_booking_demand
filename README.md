# Hotel Booking Demand — Reproducible Clustering Study

Unsupervised Learning project (2025/2026). A reproducible experimental study of
clustering on the *Hotel Booking Demand* dataset.

## Repository structure

```
.
├── README.md
├── environment.yml          # conda environment specification
├── run_all.py               # single-entry point (Section 4.2 of the brief)
├── experiments.csv          # machine-readable experiment log (regenerated by run_all)
├── src/
│   └── get_dataset.py       # downloads the raw dataset (NOT committed)
├── notebooks/
│   ├── ANS_Task1.ipynb      # EDA, R0 representation, k-means + iK-means
│   ├── ANS_Task2.ipynb      # Ward hierarchical clustering, stability
│   ├── ANS_Task3.ipynb      # internal indices, sensitivity, cross-method ARI
│   ├── ANS_Module1.ipynb    # Extension E1: cluster-aware anomaly analysis
│   ├── ANS_Module3.ipynb    # Extension E3: fuzzy c-means
│   └── ANS_Module4.ipynb    # Extension E4: PCA dimensionality reduction
├── data/                    # raw dataset goes here (gitignored)
├── figures/                 # regenerated by run_all
└── tables/                  # regenerated by run_all
```

## Dataset

- **Source:** <https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand>
- **Reference:** António, N., de Almeida, A., & Nunes, L. (2019). *Hotel booking
  demand datasets.* Data in Brief, 22, 41–49.
  <https://doi.org/10.1016/j.dib.2018.11.126>
- **Course release used:** v1
- **MD5 checksum:** `8388523d9b568014188662c5721dee2b`
- **License / usage terms:** CC0 1.0 Public Domain (as stated on the Kaggle page).
- **Unit of analysis:** one row = one booking record.
- **Governance:** the raw CSV is **not** committed to this repository. Run
  `python src/get_dataset.py` (or download manually) to obtain it. `run_all.py`
  verifies the checksum before executing the pipeline.

## Setup

```bash
conda env create -f environment.yml
conda activate hotel-clustering
python src/get_dataset.py     # downloads data/hotel_bookings.csv
```

## Reproduce all results

```bash
python run_all.py             # full pipeline (regenerates figures/, tables/, experiments.csv)
```

`run_all.py` clears `figures/`, `tables/`, and `experiments.csv` at the start,
then executes the six notebooks in order. Every figure and table referenced in
the report is regenerated automatically.
